# ResolveOS Visual Design System

ResolveOS features a clean, high-readability, modern customer-support UI aesthetics, avoiding dark-mode AI cliches or generic chatbot interfaces.

## Color Palette & Visual Language

- **Primary Background**: Warm White / Slate `#F8FAFC`, `#FFFFFF`
- **Surface & Cards**: Soft Pearl `#F1F5F9`, Ivory Slate `#E2E8F0`
- **Primary Accent**: Emerald / Mint Teal `#0D9488`, Deep Slate Teal `#0F766E`
- **Secondary Accents**: Warm Amber `#D97706` (Awaiting Approval), Rose Red `#E11D48` (Escalation / Blocked), Indigo Violet `#4F46E5` (Agent Adaptation)
- **Typography**: Inter / Sans-serif system font stack with crisp hierarchy and micro-interactions.

## Primary Interfaces

1. **Customer Help Center**:
   - Order history lookup.
   - Interactive Issue Filing Wizard.
   - Transparent, human-readable case resolution timeline.

2. **Operations & Judge Console**:
   - Analytics header (Success rate, Autonomous rate, Awaiting approval, Replans).
   - Real-time Case Queue & Approval Queue with evidence breakdown.
   - Inventory & Policy status visualizers.
   - Dedicated **Agent Trace Inspector**: Visual flow showing `UNDERSTAND` $\rightarrow$ `EVIDENCE` $\rightarrow$ `DECIDE` $\rightarrow$ `ACT` $\rightarrow$ `VERIFY` $\rightarrow$ `ADAPT` $\rightarrow$ `RESOLVE`.
